**NOEL.SPACE — Personal Bio Website**

A modern and customizable personal bio website featuring an animated glassmorphism design, a looping video background, a music player, and animated borders.

**Features**
- Animated interface with smooth transitions and visual effects.
- Customizable accent colors and background brightness.
- Background video with loop support.
- Music player using a local MP3 file.
- Roblox profile integration with avatar and online status, when the API is available.
- Social links for Roblox and Discord.
- Custom cursor and responsive layout for desktop and mobile.

**Requirements**
- `index.html` — Main website.
- `Background.mp4` — Background video.
- `music.mp3` — Music file.

Created by NOEL. Designed for a personalized and immersive browsing experience.
